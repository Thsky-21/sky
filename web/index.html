Where Bengaluru actually happens · ಕಾಫಿ

In this city, companies start at café tables.

Founders and investors over filter coffee on 80 Feet Road. Napkin maths. “Can you intro me to…”. Demo days in Koramangala.

This film is the opposite: three years of building alone, in one room. It ends on the plan — get out of this room. Talk to people.

    How it was madeಹೇಗೆ ಮಾಡಿದ್ದು

    I didn't draw a single frame by hand. I wrote the story, then directed it line by line in code, with Claude Code as my crew. Every face, every lamp flicker, every page is a function.

    Fitting, for a film that says real problems don't come from prompts: the story came from me. The code came from a lot of them.

    Like everything else I've built, it isn't finished. I shipped it anyway.
